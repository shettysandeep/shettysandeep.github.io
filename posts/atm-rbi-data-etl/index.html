RBI’s Bankwise ATM/POS/Card Statistics data

The Bankwise ATM/POS/Card Statistics is a collection of spreadsheets with monthly indicators of some banking statistics, such as the number of ATMs, active credit and debit cards, monthly volume and value of payments on debit and credit transactions, across all banks operating in the country. The data goes back to the 2000s and are available here on the RBI website.

Downloading the data

Below is the code to scrape the links to the spreadsheets from the RBI website and download them. The code uses requests and BeautifulSoup to extract the links to the spreadsheets, filters for only those that end with “XLSX”, and then downloads each file using urllib.request.urlretrieve.

from bs4 import BeautifulSoup
import requests

url = "https://rbi.org.in/scripts/atmview.aspx"
response = requests.get(url)
soup = BeautifulSoup(response.content, 'html.parser')

# Extract links from td elements
links = []
for td in soup.find_all('td'):
    link = td.find('a')
    if link and link.get('href'):
        links.append({
            'text': link.get_text(strip=True),
            'href': link['href']
        })

With the links extracted, we can create a DataFrame and filter for only those that end with “XLSX”, which are the spreadsheets we want to download.

import pandas as pd
import numpy as np

dt=pd.DataFrame(links)
dt['text']=dt['text'].replace(r'^\s*$', np.nan, regex=True).ffill()
dt= dt[dt.href.str.endswith("XLSX")]

To download the files using the links extracted above, we write fetch_data function that takes a URL and an optional file name, and uses urllib.request.urlretrieve to download the file. The loop iterates over the filtered links and downloads each spreadsheet.

import urllib.request    
def fetch_data(url, file_name=None):
    urllib.request.urlretrieve(url, file_name )

for links in dt.href:
    print(links)
    fil = links.split("/")[-1]
    fetch_data(links, fil)

Pain points in using the data

The 2025 spreadsheets are largely standardized, however, the data is organized in a way that is not immediately machine-readable. Multiple levels of hierarchical column headings and metadata embedded in the file names and sheet names make it difficult to parse the data quickly for further analysis. The overhead of processing could be discouraging. It’d be ideal if RBI restructures or at least shares a format that is machine-readable so more effort is directed towards using the data in interesting ways.

Bank type: Private, public, foreign banks

The banks are grouped by their type: private, public or foreign sector banks. The type information is a row separator dividing the banks. To incorporate this information in the tabular dataset, I created another file where the bank names were mapped to their respective type. This file is called bank_sector_map.csv. This file has two columns: bank_name and type (with values ‘private’, ‘public’, ‘foreign’). The advantage of this approach is that it creates a separate table in a database sense and makes it easy to add new bank level information or for adding new banks into the fold.

# Import and merge bank_sector_map.csv

Month-Year of the data

This information was embedded in the sheet name or file name in a non-standardized way (sometimes “May2025” and other times as “202512” in the file name that looks like ATM122025010824B80F314664BFB1DA8F17935161.XLSX). I had to extract this information from the sheet name (below) and create a new variable time_period to capture the month-year of the data for each row. This is crucial for any time series analysis or trend analysis over time.

Combining the monthly data

Below is the code for combining the monthly data from the multiple spreadsheets into a single DataFrame for analysis. The function func_combine reads each spreadsheet (ignore the headers from the top and some footnote), processes it to extract the relevant data, rename the columns and then loop through all the files into a single DataFrame dat0.

# write a function to read multiple files and combine the data

def func_combine(path2file):
    dat1 = pd.read_excel(path2file,
    index_col=0,
    usecols="B:AC",
    skiprows=9,
    skipfooter=28
    )
    dat1 = dat1.dropna(axis=1, how="all")
    # add column to grab meta data in filename
    sheetname = pd.ExcelFile(path2file).sheet_names[0]
    dat1['file_name'] =  sheetname
    # rename column names
    old_new = dict(zip(dat1.columns.to_list(), col_dict))
    dat1.rename(columns=old_new, inplace=True)
    dat1.reset_index(drop=True, inplace=True)
    return dat1

Applying the function to all files in the directory that match the pattern “ATM…XLSX”

from pathlib import Path
import glob
fdata = Path(".")
flist=list(fdata.glob("*ATM*"))
dat0 = pd.DataFrame()
for file1 in flist:
    dat1 = func_combine(file1)
    dat0 = pd.concat([dat0,dat1])

Cleaning the data

Grab the time period from the sheet names

After removing some rows that held totals across banks on different variables, I extracted and added month-year to the data. The month and year of the data were embedded in the sheet names, which were in this format “For Website April 2025” or similar. These were extracted and then converted to datetime format like ‘April 2025’ or similar.

dat0.dropna(subset=['bank_name'], inplace=True)
dat0['time_period']=dat0.file_name.str.replace("For Website ", "")

try:
    dat0['time_period'] = pd.to_datetime(dat0['time_period'], format='%B %Y')
except Exception:
    # fallback to pandas' parser
    dat0['time_period'] = pd.to_datetime(dat0['time_period'], errors='coerce')
    if dat0['time_period'].isna().any():
        print("Warning: some time_period values could not be parsed and are NaT")

Add type of bank: private, public or foreign

Mapping the bank names to their respective sectors (private, public, foreign) using the bank_sector_map.csv file that we created earlier. This will allow us to analyze the data by bank type.

# Import and merge bank_sector_map.csv
bank_sector_map = pd.read_csv("bank_sector_map.csv")
dat0 = dat0.merge(bank_sector_map, on='bank_name', how='left')
